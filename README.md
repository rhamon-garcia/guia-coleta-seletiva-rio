# Onde jogo isso? — Guia de coleta seletiva do Rio

Aplicação web de página única (HTML, CSS e JS embutidos) com as sete lixeiras do padrão
CONAMA 275/2001, busca rápida por item e a jornada de cada resíduo na cidade do Rio de Janeiro.

- **Ver online:** https://rhamon-garcia.github.io/guia-coleta-seletiva-rio/
- **Busca "Onde jogo isso?":** digite o item (ex.: `pilha`, `caixa de pizza`, `borra de café`) e o guia indica a lixeira e abre a aba correspondente.
- **Conteúdo:** guia Pode/Não pode, dicas de preparo e storytelling de economia circular com Compostaê, Rio Eco Pets, Coopama, Green Eletron e o CTR Rio.

Fonte única: `index.html`. Sem build, sem dependências locais — só Google Fonts e Lucide via CDN.

Guia educativo, sem vínculo oficial com as entidades citadas.
